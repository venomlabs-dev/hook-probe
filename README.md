# venom-hook-probe

A test plugin from Venom Labs. It ships one hook of each type (`command`, `mcp_tool`, `http`, `prompt`, `agent`) so we can see which ones the plugin directory accepts. It does nothing useful; don't install it.

Install (for testing only): `/plugin install venom-hook-probe --marketplace venomlabs-dev/hook-probe`

The real plugin is [venomlabs-dev/plugin](https://github.com/venomlabs-dev/plugin).
